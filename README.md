🌙 SleepTracker — персональный трекер сна (MVP)

SleepTracker — это минималистичный Telegram-бот для персонального отслеживания сна.
Он помогает фиксировать время засыпания и пробуждения, показывать длительность сна и формировать осознанное отношение к режиму отдыха.

Проект создан как лёгкий, быстрый и расширяемый MVP, без лишних зависимостей и сложной логики.

🚀 Возможности (MVP)
 
😴 Фиксация момента отхода ко сну

☀️ Фиксация пробуждения

⏱ Подсчёт длительности сна

🧠 Формирование привычки регулярного сна

💡 Основа для дальнейшей аналитики и AI-рекомендаций

Людей, которые хотят улучшить качество сна

Тех, кто засиживается ночью и теряет энергию

Специалистов с плавающим графиком

Всех, кто понимает: сон = энергия, концентрация, здоровье

🛠 Установка и запуск
git clone https://github.com/rolloerro/SleepTracker.git
cd SleepTracker
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt


Создайте .env:

BOT_TOKEN=your_telegram_bot_token


Запуск:

python bot.py
